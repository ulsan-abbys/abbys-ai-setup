# 실습 30분

## 0) 준비물 체크

- Windows PC와 PowerShell
- Git, Claude Code 또는 codex 하나의 설치와 로그인
- [README의 공식 설치 링크](../README.md)
- 내 업무 주제 하나와 비밀 정보가 없는 자료

## 1) 폴더 만들고 템플릿 복사 (5분)

[README의 5분 세팅](../README.md)을 따라 저장소를 내려받으세요. 저장소 폴더에서 실행합니다.

```powershell
$setup = (Get-Location).Path
$project = "$env:USERPROFILE\Documents\애비스AI실습"
New-Item -ItemType Directory -Force -Path $project | Out-Null
Copy-Item -Path .\templates\AGENTS.md, .\templates\CLAUDE.md, .\templates\STATE.md -Destination $project -Confirm
Set-Location $project
claude
# 또는 codex
```

기존 파일이 있으면 덮어쓰기 전에 확인하세요. 첫 말은 “STATE.md 읽고 시작해”입니다.

## 2) AGENTS.md를 내 일로 채우기 (10분)

아래 요청문을 입력하고 질문에 답하세요.

```text
나를 인터뷰해서 AGENTS.md를 40줄 안으로 채워 줘.
내 일, 결과물을 볼 사람, 끝났다는 기준을 한 번에 하나씩 물어봐.
모르는 내용은 추측하지 말고, 기존 안전 규칙은 유지해.
답을 모으면 초안을 보여 주고 내가 확인한 뒤 파일에 반영해.
```

[블로그 예시](../templates/examples/blog/AGENTS.md) 또는 [공부 노트 예시](../templates/examples/study-notes/AGENTS.md)를 참고하세요.

## 3) 첫 작업과 STATE.md 확인 (10분)

```text
STATE.md 읽고 시작해.
내 업무에 맞는 이번 주 할 일 3개를 표로 제안해.
끝나면 STATE.md에 지금 하는 일, 정한 것, 다음에 할 일을 정리하고
updated:를 실제 작업 시각으로 갱신해. 내가 정하지 않은 것은 질문으로 남겨 줘.
```

`STATE.md`를 직접 여세요. 날짜가 바뀌었는지, 실제로 정한 내용만 들어갔는지 확인합니다.

## 4) 점검하고 결과 공유 (5분)

AI 도구를 종료하고 PowerShell에서 실행합니다.

```powershell
Set-Location $setup
powershell -ExecutionPolicy Bypass -File tools\check_setup.ps1 -Path $project
```

세 파일이 통과했는지 확인하세요. 도구 미설치는 안내이며 파일 점검 실패가 아닙니다. 공유할 때 개인 경로와 민감한 내용은 빼고 점검 결과만 나눕니다.
