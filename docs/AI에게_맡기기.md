# AI에게 맡기기

Claude Code 또는 codex를 저장소 맨 위 폴더에서 켜세요. 다른 폴더에서 작업한다면 이 저장소의 실제 경로도 알려 주세요. 아래 요청문을 하나씩 복사합니다.

## (a) 단계별 세팅

```text
이 저장소 README와 guides를 읽고 내 PC에 세팅을 단계별로 도와줘. 각 단계마다 확인받고 진행해.
```

## (b) 내 규칙 채우기

내 프로젝트 폴더에서 실행하고 요청하세요.

```text
나를 인터뷰해서 AGENTS.md를 40줄 안으로 채워 줘
```

## (c) 오늘 상태 저장

```text
STATE.md를 오늘 한 일 기준으로 고쳐 줘
```

## (d) 업무에 맞게 조정

`○○`를 내 업무로 바꿉니다.

```text
이 세팅을 내 업무(○○)에 맞게 바꿀 점 3가지를 제안해
```

파일을 고친 뒤에는 내용을 직접 읽고 [점검 스크립트](../tools/check_setup.ps1)를 실행하세요.

## 새 기법을 만들면

(1) `guides/`에 `NN_제목.md` 형식으로 문서를 추가합니다. 기존 번호 다음을 씁니다. 예: `05_내_업무_요령.md`.

(2) 아래 구성으로 짧게 적습니다.

```markdown
# 요령 제목

## 문제
어떤 일이 불편했나요?

## 해결
어떤 요청이나 방법을 썼나요?

## 해 본 결과
무엇으로 시험했고 어떤 결과가 나왔나요?

## 주의
어떤 경우에 쓰면 안 되거나 확인이 필요한가요?
```

(3) 비밀번호·API 키·개인정보를 빼고, README 목차에 새 문서 링크를 추가합니다.

(4) 변경 내용을 PR(변경 제안)로 공유합니다. PR 양식에 바꾼 이유와 직접 해 본 결과를 적으세요. 게시와 공유는 사람이 결정합니다.
