# 새 노트북에서 처음부터 — 15분 세팅

유지관리자: [샌드박스 점검](샌드박스_점검.md)에서 명령 하나로 깨끗한 윈도우의 설치 경로를 다시 확인하세요.

> ✓ 2026-11-07 Windows Sandbox(아무것도 없는 윈도우 11)에서 3~8단계를 실제로 돌려 확인: uv 설치 7초, Claude Code 설치 25초, ZIP 받기 2초, 첫 `uv run`(파이썬 자동 다운로드 포함) 4초, 테스트 47개 통과.

> 아무것도 깔리지 않은 윈도우 노트북 기준입니다. 관리자 권한은 필요 없습니다.
> 명령은 **PowerShell**에 한 줄씩 붙여 넣습니다. (시작 메뉴 → "PowerShell" 검색. 프롬프트가 `PS C:\`로 시작하면 맞습니다.)
> 설치가 끝날 때마다 **PowerShell 창을 닫고 새로 여세요.** 새 명령은 새 창에서만 잡힙니다.

## 준비물

| 항목 | 기준 |
|---|---|
| 윈도우 | 10 (1809 이상) 또는 11, RAM 4GB 이상 |
| 구독 | Claude Pro 이상 (무료 플랜은 Claude Code 불가) — codex를 쓰려면 ChatGPT Plus |
| 회사 노트북 | 개인 구독 로그인·설치가 회사 보안 규정에 맞는지 먼저 확인 |

## 1. Git (2분) — 저장소를 받기 위해

```powershell
winget install --id Git.Git -e
```
새 창에서 `git --version` → 버전이 나오면 성공.
Git이 있으면 Claude Code가 Bash 도구도 쓸 수 있습니다 (없으면 PowerShell로 동작).

**`winget`이 없다고 나오면** (깨끗한 윈도우·일부 회사 PC에서 실제로 없음 — 2026-11-07 샌드박스 확인):
- https://git-scm.com/downloads/win 에서 설치 파일을 받아 기본값으로 설치하거나,
- Git 없이 5번 단계에서 **ZIP으로 받기**를 쓰세요. 실습은 Git 없이도 끝까지 됩니다.

## 2. Claude Code (2분)

```powershell
irm https://claude.ai/install.ps1 | iex
```
진행 표시 없이 끝납니다. 새 창에서 `claude --version` → 버전이 나오면 성공.
`claude`가 없다고 나오면: https://code.claude.com/docs/en/troubleshoot-install

## 3. uv (1분) — 파이썬과 패키지를 한 번에

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
새 창에서 `uv --version`. 파이썬은 따로 깔 필요 없습니다 (uv가 알아서 받습니다).

## 4. (선택) codex

```powershell
winget install OpenJS.NodeJS.LTS
npm install -g @openai/codex
```
새 창에서 `codex` → "Sign in with ChatGPT". 윈도우 세부 안내는 공식 문서를 먼저 확인하세요: https://developers.openai.com/codex
오늘 실습은 **Claude Code만으로 충분합니다.**

## 5. 저장소 두 개 받기 (1분)

```powershell
mkdir $HOME\abbys; cd $HOME\abbys
git clone https://github.com/ulsan-abbys/abbys-ai-setup
git clone https://github.com/ulsan-abbys/abbys-content-frame
```

Git이 없으면 (PowerShell):
```powershell
mkdir $HOME\abbys; cd $HOME\abbys
foreach ($r in 'abbys-ai-setup','abbys-content-frame') { Invoke-WebRequest "https://github.com/ulsan-abbys/$r/archive/refs/heads/main.zip" -OutFile "$r.zip" -UseBasicParsing; Expand-Archive "$r.zip" .; Rename-Item "$r-main" $r }
```

## 6. 블로그 뼈대 돌려 보기 (2분)

```powershell
cd $HOME\abbys\abbys-content-frame
uv run frame graph
uv run frame check "examples\clinic\초안\01_겨울철-가려움-보습.md"
```
처음 한 번은 uv가 파이썬과 패키지를 받느라 조금 걸립니다. `frame check`가 **분량 미달 1건**을 내면 정상입니다 (예시 초안이 일부러 짧습니다).

## 7. Claude에게 블로그 글을 맡기기 (5분)

```powershell
cd $HOME\abbys\abbys-content-frame\examples\clinic
claude
```
처음 실행하면 브라우저가 열리고 로그인합니다. 그다음 이렇게 말합니다:

```
STATE.md를 보고, 새 주제 "환절기 두피 가려움"으로 초안/02와 대본/02를 만들어 줘. 끝나면 STATE.md도 고쳐.
```

끝나면 `/exit`로 나와서 점검합니다:
```powershell
cd $HOME\abbys\abbys-content-frame
uv run frame check "examples\clinic\초안\<새로 생긴 파일 이름>.md"
```
점검에서 걸린 것을 Claude에게 "frame check 결과를 보고 고쳐 줘"라고 넘기면 루프가 됩니다 (최대 2번).

## 8. 내 폴더 세팅 점검 (1분)

```powershell
powershell -ExecutionPolicy Bypass -File $HOME\abbys\abbys-ai-setup\tools\check_setup.ps1 -Path $HOME\abbys\abbys-content-frame\examples\clinic
```
