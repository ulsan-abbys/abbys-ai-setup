# 권장 설정

설정 이름은 버전에 따라 바뀔 수 있으니 공식 문서를 먼저 확인.

세 파일로 먼저 시작하고, 아래 설정은 내용을 이해한 뒤 적용하세요. 기존 설정이 있으면 필요한 항목을 합칩니다.

## Claude Code

프로젝트의 `.claude/settings.json`에 넣는 예입니다. [공식 설정 문서](https://code.claude.com/docs/en/settings)를 확인하세요.

```json
{"permissions": {"deny": ["Read(./.env)", "Read(./secrets/**)"]}}
```

`.env`와 `secrets` 아래 파일을 Read로 읽지 못하게 하는 예입니다. 비밀번호·API 키를 파일에 쓰지 않는 원칙도 함께 지키세요.

같은 예제가 [templates/.claude/settings.json](../templates/.claude/settings.json)에 있습니다. 기본 세 파일 복사에는 포함되지 않습니다.

| 기능 | 사용법 |
|---|---|
| 계획 먼저 | `Shift+Tab`으로 plan 모드를 선택합니다. |
| 새 대화 | 상태를 저장한 뒤 `/clear`를 씁니다. |
| 초기 규칙 만들기 | `/init`을 씁니다. 이미 템플릿이 있다면 기존 내용을 먼저 확인합니다. |

## codex

`%USERPROFILE%\.codex\config.toml`의 예입니다. PowerShell에서 사용자 폴더는 `$env:USERPROFILE`로 참조합니다. [공식 설정 문서](https://developers.openai.com/codex/config-reference/)를 확인하세요.

```toml
model_reasoning_effort = "medium"
approval_policy = "on-request"
sandbox_mode = "workspace-write"
```

| 항목 | 뜻 |
|---|---|
| `model_reasoning_effort` | 추론 깊이를 medium으로 둡니다. |
| `approval_policy` | 필요할 때 승인을 요청하도록 둡니다. |
| `sandbox_mode` | 쓰기 범위를 작업 공간으로 제한합니다. |
