# 토큰 아끼는 습관

강의·공식 가이드에서 정리한 7가지 습관입니다. 토큰은 AI가 읽고 쓰고 생각할 때 쓰는 사용량 단위입니다.

| 습관 | 왜 |
|---|---|
| (1) 규칙 파일은 짧게 | 대화마다 읽는 규칙이 길면 사용량도 늘어납니다. |
| (2) 다시 설명하지 말고 STATE.md | 지난 맥락을 반복 입력하는 양을 줄입니다. |
| (3) 큰 일은 계획 모드 먼저 | 잘못 만든 뒤 고치는 비용을 줄입니다. |
| (4) 일이 바뀌면 새 대화 | 지난 대화가 계속 따라오는 부담을 줄입니다. Claude Code에서는 `/clear`를 씁니다. |
| (5) 추론 깊이는 기본(medium) | high는 생각하는 데 더 많은 토큰을 씁니다. |
| (6) 막연한 “다시 검토해” 금지 | 기준 없이 한 바퀴 더 돌지 않도록 “원문과 숫자 3개를 대조해”처럼 요청합니다. |
| (7) 서브에이전트 대량 투입 금지 | 에이전트마다 토큰을 따로 쓰므로 필요한 일만 나눕니다. |

새 대화 전에 `STATE.md`를 갱신하세요. 다음 대화의 첫 말은 “STATE.md 읽고 시작해”입니다.
