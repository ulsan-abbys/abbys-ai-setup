# 세 도구가 읽는 파일

제공된 원문의 비교표입니다. 이 저장소 실습은 Claude Code 또는 codex 하나로 시작합니다.

| | codex | Claude Code | agy (Antigravity) |
|---|---|---|---|
| 프로젝트 규칙 파일 | `AGENTS.md` | `CLAUDE.md` (`AGENTS.md`는 직접 안 읽음) | `AGENTS.md` 또는 `GEMINI.md` |
| 전역 규칙 파일 | `%USERPROFILE%\.codex\AGENTS.md` | `%USERPROFILE%\.claude\CLAUDE.md` | `%USERPROFILE%\.gemini\GEMINI.md` |
| 자동 생성 | `/init` | `/init` | 공식 `/init` 미확인 → 직접 작성 |
| 계획 먼저 | `/plan` | `Shift+Tab` (plan 모드) | `/plan` |
| 크기 권장 | 150줄 이내 (합산 32KiB 잘림) | 200줄 이하 | 파일당 24KB |
| 공식 가이드 | [AGENTS.md](https://developers.openai.com/codex/guides/agents-md/) · [설정](https://developers.openai.com/codex/config-reference/) | [메모리](https://code.claude.com/docs/en/memory) · [베스트 프랙티스](https://code.claude.com/docs/en/best-practices) | [규칙](https://antigravity.google/docs/rules-workflows) · [베스트 프랙티스](https://antigravity.google/docs/cli/best-practices) |

공통 세팅은 `AGENTS.md` 한 장입니다. codex·agy는 그대로 읽고, Claude Code는 `CLAUDE.md`에 아래 한 줄을 둡니다.

```text
@AGENTS.md
```

## Windows 주의점

- 심볼릭 링크를 쓰지 않습니다. 개발자 모드·관리자 권한 문제를 피하려고 한 줄 참조를 씁니다.
- 항상 프로젝트 맨 위 폴더에서 실행하세요. 원문 운영자 실측에서는 하위 폴더에서 `@` 참조가 펼쳐지지 않은 사례가 있었습니다.
- `STATE.md`는 지금 상태입니다. 규칙에 따라 시작할 때 읽고 끝날 때 고칩니다.
